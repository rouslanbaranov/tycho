## Limits

The binding uses three public HTTP-cache sources. RFC 5861 is Informational
and uses SHOULD NOT; RFC 9111 is Standards Track STD 98 and supplies the
permission rule, but its MUST NOT applies to HTTP caches. The sources do not
test a cache implementation, define a single refresh owner, specify a
refresh-failure metric or prove that an application cache behaves like an HTTP
cache. The owner section and card label the single-owner, telemetry and
owner-specific failure-signal rules as Tycho guidance. The `invariant` and
`failure_recovery` states are `supported` only because the claims separate the
source-supported window and fallback from those Tycho additions; a reviewer
that requires every word to be source-quoted should treat the dimensions as
partial instead.

MDN is living documentation; the binding revision is the raw HTML digest, and
the canonical text digest is an extraction, not an upstream identifier. The
source register keeps the MDN reading status section-scoped rather than
claiming a full-page read. No independent AI review, owner acceptance,
promotion or production observation is claimed.
