# Initial roadmap

1. Establish project independence, agent rules, and boundary checks.
2. Propose audience, coverage, table of contents, and three bounded pilot contracts.
3. Implement and exercise strict metadata and source schemas, generated index, structural/link validation, and minimal graph integrity checks where a graph is justified.
4. Research and review the three pilot slices; establish an evidence-grounded quality question set and readiness rubric.
5. Revise the methodology from pilot findings, then author in dependency order with bounded checkpoints.
6. Evaluate retrieval needs from real questions before selecting lexical search, embeddings, or MCP delivery.

Only the initial scaffold is delivered now. No whole-book generation or infrastructure implementation is implied by the roadmap.
