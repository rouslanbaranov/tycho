# Initial public-source discovery contract

Date: 2026-10-18. Status: first-pass inventory complete; substantive reading pending.

## Question and intended reader

Which independent public primary sources and authoritative references should support an evidence-based System Design book for engineers and AI agents?

## Scope

Books, scientific papers, standards, architecture references, official documentation and maintainers' implementations. Mandatory tracks include Kafka, PostgreSQL, reactive Java, virtual threads, CI/CD, deployment, sharding, pooling, scaling, high load and workload dependence, and metrics architecture. Additional areas include monolith/SOA/microservices, caching, transactions/idempotency, search/data models, reliability, security, traceability and recovery.

## Exclusions

No private sources, employer-derived material, paid content extraction without access, bulk mirroring, implementation delegation, benchmarks, whole-book generation or unsupported latest-version claims.

## Completion criteria for this pass

- Stable source IDs, public origin, access/reading state, version policy, planned use and reuse limitations recorded.
- Mandatory tracks mapped to source IDs and concrete implementations.
- Commercial/bibliographic and pending-access records distinguished from usable public research entries.
- Gaps, next action and limits explicit; all content in English.
- Register structure, source references, generated catalogue freshness and project boundary checks pass.

## Remaining work

Pin relevant versions and sections for three pilot research slices, inspect complete required evidence, and synthesize original explanations. A discovery record is never a verified architecture claim.
