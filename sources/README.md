# Public source register

`register.json` is the canonical admitted-source inventory. It starts empty. Its schema is planned.

Each future entry must record a stable ID, title, public URL, author/publisher, source kind, version/revision or publication date, access date, public-origin admission decision, licensing/reuse notes, exact supported scope, and reading status. Do not store rejected source contents or confidential identifiers.

Technical pages cite exact source entries and relevant sections. Do not mark a source read merely because its landing page was visited. Independence admission and technical correctness review are separate decisions.
